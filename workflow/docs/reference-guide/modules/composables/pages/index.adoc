= Composables
:navtitle: Composables

Composables are higher-level combinators that coordinate multiple concurrent workflow steps.
They accept a predicate and a set of `WorkflowStepResult` instances, and return a `CombinatorWorkflowStepResult`.

[cols="<,<,<"]
|===
|Combinator |Resolves When |Short-circuits?

|xref:all-match.adoc[allMatch] |All match, or first non-match |Yes
|xref:any-match.adoc[anyMatch] |First match, or all complete |No
|xref:none-match.adoc[noneMatch] |All complete without match, or first match |Yes
|===

All composables share:

* Accept `Predicate<WorkflowStepResult>` and varargs `WorkflowStepResult...`
* Return `CombinatorWorkflowStepResult` with `matched()` and `unmatched()` accessors
* Losers are **not** auto-cancelled
* `cancel()` propagates to all sub-results
* Replay-safe via event-sourced timestamp ordering
