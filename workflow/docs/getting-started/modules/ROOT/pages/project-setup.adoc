== Module Overview

The Axon Workflow Engine consists of four modules:

[cols="<,<"]
|===
|Module |Purpose

|`runtime` |Core engine: primitives, combinators, execution, configuration
|`dsl` |DSL layers for Java (`SimpleWorkflowContext`) and Kotlin (`Kontext`)
|`test` |Testing utilities: `AbstractDeclarativeTestBase`, `DelayedPublisher`
|`example` |Example workflows demonstrating all features
|===
