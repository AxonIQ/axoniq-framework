= Getting Started
:navtitle: Introduction

Welcome to the Axon Workflow Engine Getting Started Guide!

Building reliable business workflows is hard.
Order fulfillment, loan applications, employee onboarding — these processes need audit trails, crash recovery, and scalability.
Event sourcing delivers all of that, but comes with significant complexity: command handlers, event handlers, saga patterns, and manual state management.

The Axon Workflow Engine bridges that gap.
You write simple, imperative business logic, and the engine handles event sourcing, state persistence, and crash recovery automatically.

The engine is built on four *primitives* and three *composables*:

*Primitives* — the four core building blocks:

* *Execute* — Run actions and tasks (synchronous or asynchronous)
* *WaitFor* — Suspend until an external event arrives
* *Payload* — Modify workflow state durably
* *Terminate* — End a workflow or cancel individual steps

*Composables* — higher-level combinators for parallel work:

* *allMatch* — Guard ensuring all results match a predicate
* *anyMatch* — Race combinator where the first matching result wins
* *noneMatch* — Guard ensuring no results match a predicate

== About this tutorial

In this tutorial, you will build an *Order Fulfillment* workflow step by step.
The workflow will reserve stock, initiate payment, wait for payment confirmation, store transaction details, and then ship the order and notify the customer in parallel.

Along the way, you will learn each core concept:

. *xref:project-setup.adoc[Project Setup]* — Add dependencies and define domain events
. *xref:first-workflow.adoc[Your First Workflow]* — Create a minimal workflow that executes actions
. *xref:waiting-for-events.adoc[Waiting for Events]* — Suspend the workflow until payment is confirmed
. *xref:payload-and-state.adoc[Payload and State]* — Manage durable workflow state across steps
. *xref:step-orchestration.adoc[Step Orchestration]* — Ship and notify the customer concurrently
. *xref:testing-workflows.adoc[Testing Workflows]* — Write integration tests for your workflow
