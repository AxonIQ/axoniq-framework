= Getting Started
:navtitle: Introduction

The Axon Workflow Engine is an extension for Axon Framework 5 that lets you write simple, imperative business logic while the engine handles event sourcing, state persistence, and crash recovery automatically.

In this tutorial, you will build a workflow step by step, learning each core concept along the way:

. **xref:project-setup.adoc[Project Setup]** -- Add dependencies and understand the module structure
. **xref:first-workflow.adoc[Your First Workflow]** -- Create a minimal workflow that executes actions
. **xref:waiting-for-events.adoc[Waiting for Events]** -- Suspend a workflow until an external event arrives
. **xref:payload-and-state.adoc[Payload and State]** -- Manage durable workflow state across steps
. **xref:parallel-steps.adoc[Parallel Steps]** -- Run concurrent steps and coordinate their results
. **xref:testing-workflows.adoc[Testing Workflows]** -- Write integration tests for your workflow definitions
