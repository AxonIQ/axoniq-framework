This directory includes all code and docs written during PoC phase of the multi tenancy feature.

However, it would be a shame if this goes to waste, so as previsouly done with `_archive`: The complete git history of
the poc and the old AF4 extension is preserved here and it is preferable to use `git mv` to move the files to the new
target directory.
