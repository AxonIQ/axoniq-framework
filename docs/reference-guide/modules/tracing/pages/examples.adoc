A command sent through Axon Server produces this trace shape:

----
CommandBus.dispatch BookRoom                     [PRODUCER]
+- CommandBusConnector.dispatch BookRoom         [PRODUCER]
   +- CommandBusConnector.handle BookRoom        [CONSUMER]
      +- CommandBus.handle BookRoom              [CONSUMER]
         +- BookRoomHandler.handle(BookRoom)     [INTERNAL]
----

== Streaming event processing

The default streaming topology creates a batch trace and links each event-processing span to its publisher:

----
StreamingEventProcessor.batch                         [INTERNAL]
+- EventProcessor.process RoomBooked                  [CONSUMER]
   |  link: EventSink.publish RoomBooked
   +- RoomAvailabilityProjector.on(RoomBooked)        [INTERNAL]
----

One batch can contain events from different publishers.
Each `EventProcessor.process` span links to its own publisher.
This describes the trace topology only and makes no assumption about scheduling, threads, or processing location.

Set `distributed-in-same-trace` to select a topology where eligible process spans use the publisher span as parent:

[source,yaml]
----
axon:
  tracing:
    event-processor:
      distributed-in-same-trace: true
----

The `distributed-in-same-trace-time-limit` determines eligibility.
Events outside the time limit start a new trace linked to their publisher.

== Subscription-query updates

An update has a transport parent-child relationship and a link to the subscription:

----
QueryBus.emitUpdate
+- QueryBusConnector.queryUpdate RoomView             [PRODUCER]
   +- QueryBusConnector.queryUpdate RoomView          [CONSUMER]
      +- link: QueryBus.subscriptionQuery WatchRoom
----

The subscription setup, initial response, and update transport spans carry `messaging.message.conversation_id`.

== Jaeger export

Point an OTLP HTTP exporter at Jaeger:

[source,yaml]
----
management:
  otlp:
    tracing:
      endpoint: http://localhost:4318/v1/traces
----

`TracingJaegerIntegrationTest` starts Jaeger with Testcontainers, dispatches a command, and verifies the exported trace through Jaeger's HTTP API.
