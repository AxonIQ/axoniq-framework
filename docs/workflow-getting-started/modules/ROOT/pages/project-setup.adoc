= Project Setup
:navtitle: Project Setup

== Prerequisites

* Java 21 or higher
* Axon Framework 5.4 or higher
* Maven (Gradle works too, but this tutorial uses Maven)

== Adding dependencies

To use the Axon Workflow Engine, add the following dependencies to your `pom.xml`:

[source,xml]
.pom.xml
----
<dependencies>
    <!-- Workflow Engine Java DSL (brings in the engine transitively) -->
    <dependency>
        <groupId>io.axoniq.framework</groupId>
        <artifactId>axoniq-workflow-dsl</artifactId>
        <version>${axoniq-framework.version}</version>
    </dependency>

    <!-- Workflow Engine Test utilities -->
    <dependency>
        <groupId>io.axoniq.framework</groupId>
        <artifactId>axoniq-workflow-test</artifactId>
        <version>${axoniq-framework.version}</version>
        <scope>test</scope>
    </dependency>
</dependencies>
----

[NOTE]
====
The `axoniq-workflow-dsl` module includes both Java DSL layers (`BaseWorkflowContext` and the convenience-focused
`SimpleWorkflowContext`), which implement the author-facing `WorkflowContext` contract.
The engine (`axoniq-workflow-engine`) is a transitive dependency.
It does not depend on Kotlin.
For the Kotlin DSL (`WorkflowKontext` with the author-facing `Kontext` wrapper), add `axoniq-workflow-dsl-kotlin`.
For Spring Boot, use `axoniq-spring-boot-starter`, which includes workflow support.
====

== Module overview

The Axon Workflow Engine consists of four modules:

[cols="<,<"]
|===
|Module |Purpose

|`axoniq-workflow-engine` |Core engine: primitives, combinators, execution, configuration, and the `WorkflowContext` API
|`axoniq-workflow-dsl` |Java DSL layers (`BaseWorkflowContext` and `SimpleWorkflowContext`)
|`axoniq-workflow-dsl-kotlin` |Kotlin DSL (`WorkflowKontext` and `Kontext`)
|`axoniq-workflow-test` |Testing utilities: `AbstractWorkflowTestBase`, `DelayedPublisher`
|===
