= Installation and Setup
:navtitle: Installation

This guide covers how to install and configure Axon Data Protection in your project.

== Requirements

* **Java 21 or higher** - The module requires Java 21 as the minimum version
* **Axon Framework 5.x** - Compatible only with Axon Framework 5.0 and later
* **Spring Boot 3.x** (optional) - For Spring-based configuration

[NOTE]
====
**Breaking Change:** Axon Data Protection 5.0 is NOT backward compatible with Axon Framework 4.x or earlier versions. If you're using an older version of Axon Framework, you must use Data Protection 4.x.
====

== Maven dependency

Add the following dependency to your `pom.xml`:

[source,xml]
----
<dependency>
    <groupId>io.axoniq.framework</groupId>
    <artifactId>data-protection-core</artifactId>
    <version>5.0.0</version>
</dependency>
----

== License file

Axon Data Protection requires a valid license file. You can obtain a license from AxonIQ.

=== License file location

The license file can be placed in one of two locations:

1. **As a file** at `/path/to/axoniq-data-protection.license`
2. **On the classpath** in your resources directory

=== Configuring license path

Specify the license file location using the system property:

[source,bash]
----
-Daxoniq.dataprotection.license=/path/to/axoniq-data-protection.license
----

Or in Spring Boot `application.properties`:

[source,properties]
----
axoniq.dataprotection.license=/path/to/axoniq-data-protection.license
----

== Next steps

After adding the dependency and license file, you need to:

1. Choose and configure a xref:crypto-engines.adoc[crypto engine] (JPA, JDBC, Vault, or others)
2. Set up xref:configuration.adoc[Spring and Axon configuration]
3. Add xref:annotations.adoc[annotations] to your domain objects
